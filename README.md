# رواج · Rawaj

منصة تربط البراندات بالمسوقين وصناع المحتوى في السعودية (سناب شات، انستقرام، تيك توك)، مع ضمان للمبالغ وتحرير تلقائي بعد 72 ساعة من التسليم.

- `PROJECT_STATE.md`: حالة المشروع والمهام المتبقية وسجل التغييرات.
- `supabase/`: قاعدة البيانات (migrations) والاختبارات.
- `web/`: الواجهة الحالية ومنطق الدخول بالجوال.
